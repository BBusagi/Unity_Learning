# UniRx

Unity 响应式编程学习笔记与练习脚本。

## 内容

- [学习笔记](Note.md)：资源释放、事件处理、操作符与协程相关记录。
- [Scripts](Scripts/)：9 个练习脚本，包含 Chapter01_2、Chapter06_2。
- [教学场景](Samples/Scenes/SampleScene.unity)：保留脚本与场景的引用关系。

## 使用说明

这些文件按学习专题保存。需要运行时，将 `Scripts` 和 `Samples/Scenes` 连同对应 `.meta` 导入自己的 Unity 工程，并安装 UniRx。

原练习使用 Unity `2021.3.36f1`、UniRx `6.2.2`，包配置中 TextMesh Pro 为 `3.0.6`；具体脚本还使用 Unity UI 和 TextMesh Pro。第三方插件及 Unity 工程配置未随专题保存。
