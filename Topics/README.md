# Unity 学习专题

按主题整理学习笔记、自编脚本与配套示例资源。

| 专题 | 内容 | 入口 |
| --- | --- | --- |
| UniRx | 响应式事件、资源释放与操作符练习 | [UniRx](UniRx/README.md) |
| UniTask | 异步操作、PlayerLoop、资源与场景加载练习 | [UniTask](UniTask/README.md) |

笔记、脚本和配套示例从 `Learning_CS` 的 CSharp 目录迁入；通用 C#、LINQ 和 .NET 学习内容继续保存在 [Learning_CS](https://github.com/BBusagi/Learning_CS/tree/main/CSharp)。各专题以阅读和复用练习为主，运行环境信息见对应 README。

## 目录约定

- `README.md`：专题入口、学习资源和使用说明。
- `Note.md`：学习笔记。
- `Scripts/`：自己编写的练习脚本，保留注释和 `.meta`。
- `Samples/`：脚本配套的教学场景与小型资源。

专题按笔记和脚本组织，不包含独立 Unity 工程配置。两个专题存在同名脚本，运行练习时分别导入独立工程；具体依赖和原练习版本见专题 README。
